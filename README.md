Beauty Studio System

Sistema de gerenciamento desenvolvido para auxiliar studios de beleza na organização e controle de suas atividades internas.

O projeto tem como objetivo centralizar informações de agendamentos, clientes e controle financeiro, proporcionando uma gestão mais prática e organizada.

Objetivo:

Desenvolver uma solução para facilitar o gerenciamento diário de um studio de beleza, centralizando suas principais informações em um único sistema.

Funcionalidades:

- Gerenciamento de agendamentos
- Cadastro e gerenciamento de clientes
- Controle financeiro
- Organização das informações do studio

Tecnologias utilizadas:

- HTML5 — estrutura das páginas
- CSS3 — estilização e layout
- JavaScript — funcionalidades e interações

Status do projeto:

Em desenvolvimento

Novas funcionalidades e melhorias serão adicionadas conforme o desenvolvimento do projeto.
